[![Issues Abertas](https://img.shields.io/github/issues/DevOps-Brasil/Vagas?style=flat-square&label=Vagas%20Abertas&color=brightgreen)](https://github.com/DevOps-Brasil/Vagas/issues)

[![Stars](https://img.shields.io/github/stars/DevOps-Brasil/Vagas?style=flat-square)](https://github.com/DevOps-Brasil/Vagas/stargazers)

Repositório dedicado à divulgação de vagas para profissionais de **DevOps**, **SRE**, **Cloud**, **Platform Engineering**, **Infraestrutura** e áreas relacionadas no Brasil.

## 📋 Sobre

Este repositório funciona como um quadro de vagas para a comunidade DevOps brasileira. As vagas são publicadas como issues e automaticamente classificadas por nossos bots de triagem.

Você também pode [pesquisar e filtrar as vagas da DevOps Brasil no openings.dev](https://openings.dev/communities/DevOps-Brasil/Vagas). Cada resultado continua levando à issue original neste repositório.

> 💬 Tem dúvidas? Use as [Discussions](https://github.com/DevOps-Brasil/Vagas/discussions)!

### ✨ Funcionalidades Automáticas

- 🏷️ **Auto-labeling**: Labels adicionadas automaticamente baseadas no conteúdo da vaga
- 📍 **Detecção de localização**: Identifica estados e cidades mencionadas
- 💰 **Faixas salariais**: Classifica vagas por faixa de remuneração (BRL e USD)
- ✅ **Validação**: Verifica se todos os campos obrigatórios foram preenchidos
- 🕐 **Expiração automática**: Vagas sem interação são marcadas como stale após 60 dias

## 📝 Como Publicar uma Vaga

### 1. Use o Template

Clique no botão abaixo para criar uma nova vaga usando nosso template estruturado:

[![Publicar Vaga](https://img.shields.io/badge/🚀_Publicar_Nova_Vaga-blue?style=for-the-badge)](https://github.com/DevOps-Brasil/Vagas/issues/new?template=vaga.yml)

### 2. Preencha os Campos

O template inclui campos para:
- 🎯 **Cargo** - Nome da posição
- 🏢 **Empresa** - Nome da empresa contratante
- 📊 **Nível** - Senioridade (Júnior, Pleno, Sênior, etc.)
- 🏠 **Modalidade** - Remoto, Híbrido ou Presencial
- 📍 **Localização** - Cidade/Estado
- 📝 **Contratação** - CLT, PJ, etc.
- 💱 **Moeda** - BRL ou USD
- 💰 **Salário** - Faixa salarial (opcional, mas recomendado!)
- 📋 **Descrição** - Detalhes da vaga
- ✅ **Requisitos** - Conhecimentos necessários
- 🎁 **Benefícios** - O que a empresa oferece
- 📧 **Como se candidatar** - Instruções para aplicar

### 3. Labels Automáticas

Após publicar, nossos bots irão automaticamente adicionar labels baseadas no conteúdo!

3. ✅ Informe o máximo de detalhes possível
4. ✅ Vagas com salário são mais atrativas!
5. ❌ Não publique vagas duplicadas
6. ❌ Não use o repositório para spam ou propaganda
